# AI Assistant Instructions for simonbremner.net-astro

## Project Overview
This is a portfolio website being refactored from a blog-style site to a focused photography portfolio. Built with Astro, React, and Sanity CMS.

## Architecture Preferences
- **Tech Stack**: Maintain current Astro + React + Sanity stack
- **Rendering**: Prefer server-side rendering where possible
- **File Structure**: Keep existing folder organization in `/src/components/`, `/src/pages/`, etc.
- **Content Management**: Preserve existing Sanity schemas during refactor until new content is finalized

## Site Structure
**Target Pages:**
- **Home**: Portfolio homepage with hero and introduction
- **Gallery**: Photography gallery with masonry layout
- **About**: About/contact page

**Navigation**: Simple 3-page navigation (Home/Gallery/About) - minimal and clean

## Code Standards
- **Linting/Formatting**: Use Biome (existing config in `biome.json`)
- **TypeScript**: Strict mode enabled - maintain type safety
- **Components**: Functional components only (no class components)
- **File Extensions**: `.tsx` for React components, `.astro` for Astro components

## Content Strategy
- **Focus**: Photography portfolio (no blog content)
- **Gallery Style**: Masonry/Pinterest-style layout
- **Existing Content**: Keep current Sanity schemas temporarily during transition
- **Content Types**: Prioritize image galleries, project showcases, and personal content

## Development Workflow
- **Package Manager**: Use `pnpm` for all operations
- **Development**: `pnpm dev` for local development at `localhost:4321`
- **Build**: `pnpm build` for production builds
- **Studio**: Sanity studio in `/studio/` directory with separate package.json

## Communication Preferences
- **Approach**: Balanced explanations - not overly verbose but provide context for major changes
- **File Changes**: Use appropriate edit tools rather than code blocks
- **Structure**: Respect existing component organization and patterns

## Design Considerations
- **Responsive**: Mobile-first approach
